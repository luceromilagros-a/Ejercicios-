```markdown
# Ejercicios Básicos de Python

## 1. Saludo Personalizado
Crear una función `saludar_usuario(nombre)` que reciba un nombre como parámetro y muestre un saludo personalizado.

## 2. Contador de Letras
Crear una función `contar_letras(palabra)` que reciba una palabra y devuelva la cantidad de letras que tiene.

## 3. Mayor de Edad
Crear una función `es_mayor(edad)` que reciba una edad y devuelva `True` si es mayor de edad (≥18) o `False` en caso contrario.

## 4. Validación de Contraseña Simple
Crear una función `verificar_contrasena(contrasena)` que verifique si una contraseña tiene al menos 8 caracteres. Devuelve `True` si es válida, sino `False`.

## 5. Invertir Palabra
Crear una función `invertir_palabra(palabra)` que reciba una palabra y devuelva la misma escrita al revés usando slicing o métodos de string.

## 6. Contador de Vocales
Crear una función `contar_vocales(palabra)` que cuente cuántas vocales contiene una palabra usando un bucle `for`.

## 7. Menú de Opciones
Crear una función `mostrar_menu()` que imprima un menú con tres opciones (ej.: 1) Saludar, 2) Sumar números, 3) Salir).

## 8. Repetir Mensaje
Crear una función `repetir_mensaje(mensaje, veces)` que imprima un mensaje la cantidad de veces indicada usando un bucle `for`.

## 9. Encontrar Palabra
Crear una función `buscar_palabra(frase, palabra)` que devuelva `True` si la palabra se encuentra en la frase, o `False` si no.

## 10. Sumar Números Ingresados
Crear una función `sumar_numeros()` que pida al usuario ingresar 5 números y devuelva la suma total.
```
