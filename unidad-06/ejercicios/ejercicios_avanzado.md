# Ejercicios Avanzados de Python

## 1. Palíndromo
Crear una función `es_palindromo(cadena)` que determine si una cadena es un palíndromo ignorando mayúsculas y espacios.
_Ejemplo:_  
```python
es_palindromo("Anita lava la tina")  # True
```

## 2. Contador de Vocales y Consonantes
Crear una función `contar_vocales_consonantes(cadena)` que retorne la cantidad de vocales y consonantes en una cadena, ignorando espacios y caracteres no alfabéticos.

## 3. Invertir Cadena sin Slicing
Implementar una función `invertir_cadena(cadena)` que devuelva la cadena invertida sin usar slicing (`[::-1]`). Usar un bucle `for` o `while`.

## 4. Validación de Contraseña Compleja
Crear una función `validar_contrasena(contrasena)` que verifique si una contraseña cumple con:
- Al menos 8 caracteres.
- Contiene mayúsculas, minúsculas, números y un carácter especial (!@#$%^&*).

## 5. Contar Palabras en Frase
Crear una función `contar_palabra(frase, palabra)` que cuente cuántas veces aparece una palabra específica en una frase, ignorando mayúsculas.

## 6. Sumar Dígitos en Cadena
Crear una función `sumar_digitos(cadena)` que sume todos los dígitos presentes en una cadena usando `isdigit()` y un bucle.

## 7. Validar Email Complejo
Crear una función `validar_email(email)` que valide si un email contiene un único '@', un dominio después del punto (ej.: `.com`) y no tiene espacios.

## 8. Generar Acrónimo
Crear una función `generar_acronimo(frase)` que genere un acrónimo con las primeras letras de cada palabra en una frase.

## 9. Cifrado César
Crear una función `cifrar_cesar(cadena, clave)` que desplace cada letra por `clave` posiciones en el alfabeto, manteniendo mayúsculas/minúsculas.

## 10. Palabra Más Larga en Frase
Crear una función `palabra_mas_larga(frase)` que encuentre y devuelva la palabra más larga en una frase. Si hay empate, devolver la primera.
